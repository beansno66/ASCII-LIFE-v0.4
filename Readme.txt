This is the Second version of ASCII-LIFE!

This project is all by me and uses a modded version of My AriesN 3x3 Neural Network.
It is a simple project that allows ASCII Creatures to evolve and learn, They can change color, change their shape, and size all by Mutations!
I allow you to learn from this project and make your own version by remixing!! With credit!

This is kinda better than those trash AI Neural Network apps/websites, ASCII-LIFE is 100% hand-made, and Very fast to compute. No Generative AI """helping""" here. There is no "Generations" thing in this project. It is more realisic like that, for example, You don't have a hovering "Gen <number>" thing over your head! =)
